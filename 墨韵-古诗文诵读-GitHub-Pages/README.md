# 墨韵 · 2027 广东学考必背古诗文 32 篇

一个可直接部署到 GitHub Pages 的静态古诗文朗读网站。内容依据《2027 广东学考语文必背古诗文 32 篇及重点句》整理，包含 32 篇原文、64 段男/女声朗读音频与逐句时间轴。

> **诗词数据已内嵌在 `index.html` 中**，即使 `data.js` 没有上传，左侧目录和正文也会显示。但要听到朗读，必须同时上传整个 `audio/` 文件夹。

## 功能

- **单首朗读**：左侧选篇，点“朗读本篇”即可从第一句开始；也可点正文任意一句，从该句开始。
- **定时关闭**：5 / 10 / 15 / 20 / 30 / 45 / 60 分钟，或自定义 1–240 分钟；到点声音淡出并停止。
- **播完即停**：可设置“播完当前这一篇后关闭”，适合睡前听一篇。
- **逐句定位**：正文高亮跟随音频，点句、上一句/下一句均可跳转。
- **双音色与语速**：女声“晓晓”、男声“云希”，支持 0.8×–1.3×。
- **学习辅助**：搜索、诗/词/文筛选、收藏、已读标记、字号调节、专注模式。
- **移动端适配**：手机、平板、桌面均可用；支持系统媒体控制。

## 本地打开

Windows 双击 `启动网站.bat`，浏览器会打开 `http://127.0.0.1:8787/`。

或在本目录执行：

```bash
python -m http.server 8787
```

然后访问 `http://127.0.0.1:8787/`。不要直接双击 `index.html`，部分浏览器会限制本地音频加载。

## 发布到 GitHub Pages

### 方式一：网页上传（无需命令行）

1. 在 GitHub 新建公开仓库，例如 `mo-yun-poetry`。
2. **先解压 ZIP**，不要把 ZIP 文件本身上传到仓库。
3. 上传解压后的内容，确保仓库首页直接看到 `index.html`，而不是 `古诗文诵读/index.html` 或 `poem-site/index.html`。
4. 必须一起上传 `audio/` 文件夹（64 个 mp3），否则只能看诗词、不能朗读。
5. 打开仓库 **Settings → Pages**，选择 **Deploy from a branch → main → / (root)**，保存。
6. 约 1 分钟后访问 `https://你的用户名.github.io/仓库名/`。

> 看不到诗词时先检查：仓库根目录是否有 `index.html`；Pages 是否显示 “Your site is live at …”；地址是否带仓库名。

### 方式二：GitHub Actions

仓库已包含 `.github/workflows/pages.yml`。推到 `main` 后，在 **Settings → Pages → Source** 选择 **GitHub Actions**，工作流会自动发布。

## 目录

```text
index.html              页面、样式、32 篇内嵌数据与播放逻辑
data.js                 诗词数据源文件（可选，页面已内嵌）
audio/                  64 个 mp3（每篇男/女声各一）
audio/timings.json      时间轴源数据
favicon.svg             站点图标
启动网站.bat            Windows 本地预览
```

## 说明

朗读音频为 TTS 合成，仅用于背诵跟读；原文以教材为准。定时到点会停止朗读并保留页面，不会强制关闭浏览器标签页（浏览器不允许网页关闭非脚本打开的标签页）。
